PathFind STABLE
3D pathfinding for NPCs and enemies. Handles navigation, stuck detection, and direction to target automatically.

Setup

Declare a PathFind instance on your node. You also need a NavigationAgent3D and a target Node3D as exported fields:

[Export] public NavigationAgent3D agent;
[Export] public Node3D target;
public PathFind _Agent = new PathFind();

Initialize

Call this in _Ready() to set up the pathfinder:

_Agent.Self = this;
_Agent.Target = target;
_Agent.agent = agent;
_Agent.Init();
PropertyTypeDescription
SelfNode3DThe NPC node running the pathfinder
TargetNode3DThe node to navigate toward
agentNavigationAgent3DThe NavigationAgent3D attached to your NPC

Update

Call this every physics frame inside _PhysicsProcess():

_Agent.Update();

Move Toward Target

Use Direction_To_Target to get the movement direction and apply it as velocity:

Velocity = _Agent.Direction_To_Target * 10.0f;
MoveAndSlide();

Multiply by your desired movement speed. Call MoveAndSlide() after to apply the movement.

Full Example

[Export] public NavigationAgent3D agent;
[Export] public Node3D target;
public PathFind _Agent = new PathFind();

public override void _Ready()
{
    _Agent.Self = this;
    _Agent.Target = target;
    _Agent.agent = agent;
    _Agent.Init();
}

public override void _PhysicsProcess(double delta)
{
    _Agent.Update();
    Velocity = _Agent.Direction_To_Target * 10.0f;
    MoveAndSlide();
}
Note: Make sure your scene has a NavigationRegion3D with a baked NavigationMesh. Without it the pathfinder has no map to navigate on.
