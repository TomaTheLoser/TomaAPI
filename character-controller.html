CharacterController TPP
CharacterController STABLE
Handles all player movement — walking, sprinting, and jumping.
Pairing required: CharacterController must use the same MovementStyle as your TPP setup. Mismatched styles will cause incorrect movement.

Movement Styles

MovementStyle.Default — the character can move in all directions freely. Forward, backward, left, and right are all independent.

MovementStyle.General — the character always faces the direction it is moving. Only a single walk animation is needed — no backward or strafe animations required.

Properties

Declare these on your CharacterBody3D script:

[Export] public float Speed = 6.0f;
[Export] public float SprintSpeed = 8.0f;
[Export] public float JumpHeight = 4.0f;
[Export] public Camera3D camera;

Enable Sprint

CharacterController.Sprint = true;
CharacterController.SprintSpeed = SprintSpeed;

Update Movement

CharacterController.Update(this, Speed, JumpHeight, delta, camera,
    Toma.Behavior.MovementStyle.General);

Full Example

public override void _Ready()
{
    CharacterController.Sprint = true;
    CharacterController.SprintSpeed = SprintSpeed;
}

public override void _PhysicsProcess(double delta)
{
    CharacterController.Update(this, Speed, JumpHeight, delta, camera,
        Toma.Behavior.MovementStyle.General);
}
