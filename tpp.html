Features
CharacterController TPP
TPP STABLE
Third-person camera system. Handles alignment, collision, mouse look, and position updates.
Pairing required: TPP must use the same MovementStyle as your CharacterController. Mismatched styles will cause incorrect movement.

Movement Styles

MovementStyle.Default — the character can move in all directions freely. Forward, backward, left, and right are all independent. Works like a strafe-style controller where the character does not need to turn to move sideways or backward.

MovementStyle.General — the character always faces the direction it is moving. Moving in any direction causes the character to rotate and walk that way. Because of this, only a single walk animation is needed — no backward or strafe animations required.

Align Camera

Smoothly moves the camera behind the character. The third parameter controls how fast it snaps:

TPP.Align(this, camera, 10.0f, delta, MovementStyle.General);

Enable Collision

Prevents the camera from clipping through walls and objects:

TPP.EnableCollision(camera, this);

Update Camera

Updates the camera position. Call this every physics frame:

TPP.Update(camera, this, delta: delta);

Mouse Look

Rotates the camera with mouse movement. Call this inside _Input():

TPP.EnableMouse(camera, mouse, sensitivityX: 0.4f, sensitivityY: 0.4f);

Full Example

This example uses MovementStyle.General. CharacterController.Update() is called with the same style.

public override void _PhysicsProcess(double delta)
{
    Controller(delta);
    Third_person_camera(delta);
}

void Controller(double delta)
{
    // Must use the same MovementStyle as TPP
    CharacterController.Update(this, Speed, JumpHeight, delta, camera,
        Toma.Behavior.MovementStyle.General);
}

void Third_person_camera(double delta)
{
    TPP.Align(this, camera, 10.0f, delta, MovementStyle.General);
    TPP.EnableCollision(camera, this);
    TPP.Update(camera, this, delta: delta);
}

public override void _Input(InputEvent @event)
{
    if (@event is InputEventMouseMotion mouse)
        TPP.EnableMouse(camera, mouse, sensitivityX: 0.4f, sensitivityY: 0.4f);
}
Note: Always call EnableCollision and Update together. Skipping either one will cause incorrect camera behavior.
