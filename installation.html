Installation
Get TomaAPI set up in your Godot 4 project.

Requirements

Godot 4.x with .NET (C#) support enabled, and .NET 6 or higher.

Step 1 — Add the DLL

Copy TomaAPI.dll into your Godot project folder.

In Godot, go to Project → .NET → Add Reference and select TomaAPI.dll.

Step 2 — Add using statements

At the top of any script that uses the API, add:

using Godot;
using Toma.Behavior;
using Toma.GamePlayCore;
using Toma.System;
using Toma.Mod;

Done

You are ready to use TomaAPI. Pick a feature from the sidebar to get started.
