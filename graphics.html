TomaAPI
Graphics STABLE — Anime only
Applies visual shaders and sky styles to your world environment.
Stability notice: Only Style.Anime is stable in this release. Other styles are experimental and may produce unexpected results or change without notice.

Shader Styles

Style.Anime — a stylized look with flat shading and strong outlines. Fully stable and ready for production use.

Other styles — additional styles are defined but not yet stable. Avoid using them in production builds.

Setup

Graphics setup is async. Call it inside _Ready() with await and pass your WorldEnvironment node along with the desired style:

using Toma;
using Godot;
using graphics = Toma.Shaders.Shader.Sky;

public partial class Graphics : Node
{
    [Export] WorldEnvironment world;

    public override async void _Ready()
    {
        await graphics.Setup(world, graphics.Style.Anime);
    }
}
Note: Setup is awaitable — make sure _Ready is marked async, otherwise the shader may not finish loading before the scene starts.
